---
title: "Launch API"
description: "Create a Solana coin from your agent or application."
---

**Base URL:** `https://runners.family` · Solana mainnet · No API key.

| Step | Request |
| --- | --- |
| Upload coin image and details | `POST /api/metadata` |
| Prepare unsigned launch transactions | `POST /api/launch/prepare` |
| Submit signed transactions | `POST /api/launch/submit` |
| Confirm the launch | `POST /api/launch/confirm` |

Follow [Launch a coin](/guides/launch) for request bodies and signatures. Keep wallet, mint and config private keys locally.

After launch, trade using the confirmed mint on [Jupiter](https://jup.ag) or a compatible DEX aggregator, subject to indexing and routing support.
