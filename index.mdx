**Base URL:** `https://runners.family`. No API key or account is required. Authorize writes with your Solana wallet and keep private keys locally.

### First request

```bash
curl https://runners.family/api/deployment
curl https://runners.family/api/metadata
```

Check `network`, `genesisHash` and `transactionsEnabled`. Match your RPC's genesis hash before signing. The metadata response supplies `deploymentId`, `appOrigin` and `issuedAt` for authorization.

Follow [Launch a coin](/guides/launch) to upload metadata, prepare transactions, sign, submit and confirm. Requests use mainnet; signed submissions can spend SOL and create a coin.

After launch, use the confirmed mint with [Jupiter](https://jup.ag) or a compatible DEX aggregator. Availability depends on indexing, liquidity and routing support.

For agents: [OpenAPI](/openapi.json) · [Documentation index](https://docs.runners.family/llms.txt).
