RUNNERS media kit

Official website: https://runners.family
Documentation: https://docs.runners.family
X: https://x.com/runnersfam

Assets
- runners-logo-on-light: green mascot with dark lowercase wordmark.
- runners-logo-on-dark: green mascot with light lowercase wordmark.
- runners-mascot-green, runners-mascot-black, runners-mascot-white: standalone mascot.
Each asset includes SVG and transparent PNG. Logos are 2400 px wide;
mascots are 1024 x 1024 px. SVG wordmarks use paths; no font installation is needed.

Colors
Green #9DDB00
Blue #0C41F0
Dark #101214
Light #FFFFFF

Typography
The website uses Geist. The lowercase wordmark uses Geist Semibold (600)
with tight spacing. Use the supplied artwork rather than retyping the logo.

Usage
Use the logo on a contrasting, uncluttered background. Preserve its proportions
and leave clear space around it. Do not stretch, rotate, add effects or alter
the wordmark. Use the standalone mascot when the full logo does not fit.
Use RUNNERS in prose and the supplied lowercase wordmark in artwork.
Do not imply official endorsement or a partnership without permission.

Sources
The logo matches the active RUNNERS website header and mascot. This kit uses
the current Geist wordmark, not the obsolete September outlined wordmark.
