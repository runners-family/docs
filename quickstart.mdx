## 1. Check the deployment

```bash
curl --fail-with-body --silent --show-error \
  https://runners.family/api/deployment
```

Read `network`, `genesisHash`, `programs` and `transactionsEnabled`. The production origin serves mainnet. Match the genesis hash against your own Solana RPC before signing or sending any transaction.

## 2. Get a metadata challenge

```bash
curl --fail-with-body --silent --show-error \
  https://runners.family/api/metadata
```

The response contains `deploymentId`, `appOrigin` and `issuedAt`. Bind the returned deployment and app origin into the exact messages described in [Launching coins](/guides/launch). Use the server's `issuedAt` for the authorization time.

## JavaScript

Node.js 22 includes `fetch`; these reads need no packages.

```js
const API = 'https://runners.family';

async function read(path) {
  const response = await fetch(`${API}${path}`);
  const text = await response.text();
  let body;
  try { body = JSON.parse(text); } catch {
    throw new Error(`HTTP ${response.status}: non-JSON response`);
  }
  if (!response.ok) {
    throw Object.assign(new Error(body.error ?? `HTTP ${response.status}`), {
      code: body.code,
      status: response.status,
      retryAfter: response.headers.get('Retry-After'),
    });
  }
  return body;
}

const deployment = await read('/api/deployment');
if (deployment.network !== 'mainnet') throw new Error('Unexpected network');
console.log({ network: deployment.network, genesisHash: deployment.genesisHash });
const challenge = await read('/api/metadata');
console.log({ deploymentId: challenge.deploymentId, appOrigin: challenge.appOrigin, issuedAt: challenge.issuedAt });
```
